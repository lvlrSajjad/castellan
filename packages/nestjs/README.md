# @castellanjs/nestjs

NestJS module, guard and decorators for castellan (CASL-style abilities on Apache Casbin).

Part of [castellan](https://github.com/lvlrSajjad/castellan): CASL-style authorization DSL enforced by Apache Casbin (incubating). See the [main README](https://github.com/lvlrSajjad/castellan#readme) for docs.
